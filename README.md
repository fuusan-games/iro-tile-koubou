# いろタイル工房 〜ふーさんの宮殿の壁〜

▶ **あそぶ: https://ryowatanabe1161-svg.github.io/iro-tile-koubou/**

5色のタイルを工房から取り合い、自分の壁を仕上げるオンライン対戦ゲーム（2〜4人、空いた席は ふーさん🐻）。
スマホ・PC対応、日本語UI。サーバー不要（静的ファイル＋PeerJSのP2P）。

## 遊び方（ルール）
- タイル5色（藍・山吹・紅・墨・白磁）×20枚＝100枚。袋と箱（捨て札）。
- 工房：2人＝5つ、3人＝7つ、4人＝9つ。各ラウンドの始めに袋から4枚ずつ。中央には先手マーカー🐻。
- 手番：1つの工房から1色ぜんぶ（残りは中央へ）、または中央から1色ぜんぶ。ラウンドで最初に中央から取った人は先手マーカーも取って床へ（次ラウンドの先手）。
- 取ったタイルは1〜5段目のどれか1つへ（1段に1色・壁の同じ行に同色があると不可）。あふれは床へ（床は7枚まで、それ以上は箱へ）。
- 工房と中央が空になったらラウンド終了：満杯の段から1枚を壁の同色マスへ移して得点（単独1点／横・縦につながった枚数、両方なら合計）、残りは箱へ。未完成の段は持ち越し。
- 床の減点 −1,−1,−2,−2,−2,−3,−3（マーカーも1枠）。0点未満にはならない。
- 袋が空になったら箱のタイルを袋に戻して補充。
- だれかが横1列をそろえたラウンドの後に終了。ボーナス：横列 +2／縦列 +7／同色5枚 +10。同点は横列が多い方が上（それも同じなら同順位）。

## オンライン
- ホストのブラウザが唯一の正（合法手チェック・ふーさんの手・得点計算）。部屋コード4文字／QR／招待URL。
- ホスト：メニュー「中断してロビーに戻る」。ゲスト：「ロビーに戻りたい」「退出する」。
- 切断しても同じニックネームで入り直すと元の席に戻れる。ホストは切断中の人の番を ふーさんに代打ちさせられる。
- ホストがリロードしても「前回の部屋を再開する」で続きから（12時間以内）。
- TURNサーバーは未設定（`config.js` の `iceServers` に追加可能）。

## ふーさん🐻（CPU）
- 弱い：ほぼランダム（床は避ける）。普通：その場の得点・完成・床減点の貪欲法。強い：上位候補をラウンド終わりまで先読み（簡易モンテカルロ）＋列・色ボーナスの見込み。

オリジナルの名称・絵柄です。ほかのふーさんゲームは [ふーさんのゲームひろば](https://ryowatanabe1161-svg.github.io/fuusan-games/) から。
